# Data

Raw data is **not** committed to this repo. Download the four station files and place them here.

**Source:** CPCB / TNPCB via [data.opencity.in – Chennai hourly air quality reports](https://data.opencity.in/dataset/chennai-hourly-air-quality-reports)
(15-minute readings, Jan 2024 – Dec 2025).

Expected filenames (edit the `FILES` dict in the notebook if yours differ):

| Station | File |
|---|---|
| Manali | `chn-manali-cpcb-2024-25.csv` |
| Manali Village | `manali-village-tnpcb-2024-25.csv` |
| Kodungaiyur | `kodungaiyur-tnpcb-2024-25.csv` |
| Royapuram | `royapuram-tnpcb-2024-25.csv` |

Please check the dataset page for its license/terms before redistributing the raw files.
